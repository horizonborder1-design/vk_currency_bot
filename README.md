# 💱 VK Currency Bot

Бот для конвертации валют в ВКонтакте.

## 🔧 Поддерживаемые валюты
- евро (EUR)
- доллар (USD)  
- рубль (RUB)

## 📋 Команды
| Команда | Описание |
|---------|----------|
| `/start` или `/help` | Показать инструкцию |
| `/values` | Список доступных валют |
| `евро доллар 100` | Конвертировать 100 евро в доллары |
